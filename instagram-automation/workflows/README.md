# Automation workflow

1. Content preparation: generate a Reel concept, script, caption and hashtags.
2. Review gate: show the exact video, destination account, caption and AI disclosure choice.
3. Publishing: publish only after the owner approves the complete final payload.
4. Insights: retrieve account and Reel metrics with the authorized owner connection.
5. Reporting: summarize reach, views, engagement, saves, shares and retention when supplied by Instagram.

No workflow should auto-publish unreviewed content or request credentials in chat.
